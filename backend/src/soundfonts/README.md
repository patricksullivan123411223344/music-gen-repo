# SoundFonts added for sax

Existing banks in this folder predate this note. The saxophone files below were added for the browser SF2 loop.

## `FreePats_Tenor_Sax.sf2`

- Source: [FreePats Tenor Saxophone](https://freepats.zenvoid.org/Reed/saxophone.html#TenorSax) (small SF2, 2020-07-17)
- Samples: Versilian Community Sample Library (Versilian Studios LLC), assembled by roberto@zenvoid.org
- License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)

## `GC_Alto_Sax.sf2`

- Source: [Alto Saxophone sf2 on Musical Artifacts](https://musical-artifacts.com/artifacts/5695) (`GC_Alto_Sax.sf2`, preset “Juno Alto Sax”)
- License: [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) — attribution required
- Tone is more synth/Juno than acoustic; swap the file later without code changes if a better dedicated alto bank is found.
